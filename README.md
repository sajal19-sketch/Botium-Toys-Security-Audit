# Botium-Toys-Security-Audit
"A comprehensive security audit and risk assessment for Botium Toys, evaluating current assets and controls against the NIST CSF, GDPR, PCI DSS, and SOC standards. This project identifies security gaps, assesses business impact, and provides strategic recommendations to strengthen organizational security posture."


Objective: To assess the security program at Botium Toys, including all assets, internal processes, and compliance best practices.
Risk Profile: The organization currently has a high risk score of 8/10 due to inadequate asset management and missing security controls.
Scope: Assessment of IT-managed assets including end-user devices, ecommerce systems, legacy software, and physical storefront/warehouse security.
Compliance Gaps: * PCI DSS: Lack of encryption for credit card data and insufficient access controls.
GDPR: Need for data classification and inventorying.
SOC: Lack of least privilege and separation of duties.
Strengths: Current infrastructure includes functional firewalls, antivirus monitoring, physical locks, and CCTV surveillance.
